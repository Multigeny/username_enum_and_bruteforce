# username_enum_and_bruteforce

Инструмент для **авторизованного** тестирования веб-форм входа на собственных или официально разрешённых тестовых стендах.

Скрипт выполняет два этапа:

1. **Перечисление логинов** (username enumeration) — по разнице сообщений об ошибке определяет, какие логины существуют в системе.
2. **Подбор пароля** (dictionary attack) — для найденного логина перебирает пароли из словаря.

> ⚠️ **Внимание!** Скрипт предназначен исключительно для использования на **собственных** или **официально разрешённых** тестовых стендах (учебные лаборатории, CTF-площадки, локальные тестовые окружения). Использование против чужих систем без письменного разрешения владельца является **незаконным** и преследуется по закону. Автор не несёт ответственности за любое незаконное или неэтичное использование.

## Установка

### 1. Клонируйте репозиторий

```bash
git clone https://github.com/multigeny/username_enum_and_bruteforce.git
cd username_enum_and_bruteforce
```

### 2. Создайте виртуальное окружение (рекомендуется)

**Windows:**

```bash
python -m venv venv
venv\Scripts\activate
```

**Linux / macOS:**

```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Установите зависимости

```bash
pip install -r requirements.txt
```

Если файла `requirements.txt` нет, установите вручную:

```bash
pip install selenium
```

### 4. Установите ChromeDriver

ChromeDriver должен **строго соответствовать** версии установленного Chrome.

- Узнать версию Chrome: `chrome://version` в адресной строке.
- Скачать ChromeDriver: https://googlechromelabs.github.io/chrome-for-testing/
- Распаковать и положить `chromedriver.exe` (или `chromedriver` на Linux/macOS) в папку с проектом или в `PATH`.

**Альтернатива:** современный Selenium 4 умеет сам скачивать драйвер через `selenium-manager`. Если драйвер не найден, попробуйте обновить Selenium:

```bash
pip install --upgrade selenium
```

## Подготовка словарей

В папке проекта должны лежать два файла:

### `logins.txt` — список логинов-кандидатов (по одному на строку)

```text
admin
user
Aang
Katara
test@example.com
...
```

### `world_passwords.txt` — список паролей-кандидатов (по одному на строку)

```text
123456
password
qwerty
admin123
...
```

Оба файла должны быть в кодировке **UTF-8** (без BOM).

## Параметры (что вводить)

| Параметр                          | Описание                                                                                           |
| --------------------------------- | -------------------------------------------------------------------------------------------------- |
| **URL страницы входа**            | Полный адрес формы логина, например `http://localhost:3000/login`                                  |
| **ID поля логина**                | `id` атрибута `<input>` для логина (см. через F12 → Elements)                                      |
| **ID поля пароля**                | `id` атрибута `<input>` для пароля                                                                 |
| **ID элемента ошибки**            | `id` элемента, куда выводится сообщение об ошибке                                                  |
| **Текст ошибки неверного логина** | Точная фраза, которую показывает стенд при несуществующем логине                                   |
| **Текст ошибки неверного пароля** | Точная фраза при неверном пароле                                                                   |
| **Признак успеха**                | Режим `1` — форма входа исчезает / редирект; режим `2` — появляется уникальный элемент после входа |
| **Файлы словарей**                | Пути к `logins.txt` и `world_passwords.txt`                                                        |
| **Задержка**                      | Пауза между попытками в секундах (увеличьте для медленных стендов)                                 |

### Как узнать ID элементов

1. Откройте страницу входа в браузере.
2. Нажмите **F12** → вкладка **Elements**.
3. Наведите на поле ввода → посмотрите атрибут `id`.
4. Аналогично найдите элемент ошибки (после ввода неверного пароля).

## Как это работает

1. **Этап 1 — перечисление логинов.** Скрипт вводит каждый логин из `logins.txt` с произвольным паролем. Если появляется ошибка «логин не найден» — логин не существует, идём дальше. Если ошибка другая (например, «неверный пароль») — логин существует, запоминаем его.
2. **Этап 2 — подбор пароля.** Для найденного логина скрипт перебирает пароли из `world_passwords.txt`. Если элемент ошибки не появился (или появился элемент успеха) — пароль верный.

---

## Ограничения и известные проблемы

- **Стенд с обобщённой ошибкой** («Неверный логин или пароль») — скрипт **не сможет** перечислить логины, так как тексты ошибок одинаковы. Нужен стенд, уязвимый к username enumeration (например, TryHackMe Enumeration & Brute Force).
- **Rate limit / блокировка** — если стенд банит после N попыток, увеличьте задержку или используйте прокси.
- **`NoSuchWindowException`** — если успешный вход закрывает вкладку, скрипт трактует это как успех (обработано).
- **`StaleElementReferenceException`** — страница перерисовывается, элементы протухают; скрипт получает элементы заново на каждой итерации.
